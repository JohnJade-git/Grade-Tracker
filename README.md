# Grade Garden

A Flutter grade tracker with an animated loading screen, login and registration
forms, a semester overview, per-class averages, and an add-grade flow.

## Run

Install Flutter, then run:

```sh
flutter pub get
flutter run
```

## Notes

- Login and registration are local demo flows; no account is created and no
	credentials are sent to a server.
- Sample classes and grades are included so the dashboard is populated on first
	run. Changes remain in memory and reset when the app restarts.
- Run `flutter test` and `flutter analyze` to check the project.
